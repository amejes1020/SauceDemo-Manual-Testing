# SauceDemo – Manual Software Testing Portfolio

## Project Overview

This is a self-driven manual software testing project on the SauceDemo web application. The project demonstrates practical skills in test scenario design, test case creation, test execution, defect reporting, and AI-assisted test design.

**Application:** https://www.saucedemo.com/

**Project Type:** Manual Functional Testing  
**Testing Approach:** Positive, negative, boundary, edge-case, and end-to-end testing  
**Test Documentation:** Excel  
**AI Assistance:** ChatGPT for test scenario generation and test case review

## Objectives

- Validate key user workflows in an e-commerce demo application.
- Create structured and reusable manual test cases.
- Execute test cases and record actual results.
- Practice identifying, documenting, and retesting defects.
- Use AI to support test design while independently reviewing and executing tests.

## Modules Tested

| Module | Scope |
|---|---|
| Login | Valid and invalid credentials, required fields, error messages, keyboard interactions |
| Products | Product display, names, prices, sorting, product details, and adding products to Cart |
| Cart | Product details, multiple products, removing products, badge updates, and navigation |
| Checkout | Customer information validation, order overview, price calculations, order completion |
| Menu & Logout | Side menu, navigation options, logout, login after logout, and Reset App State |

## Testing Activities

1. Reviewed application functionality and identified test scenarios.
2. Created structured manual test cases with preconditions, steps, test data, and expected results.
3. Executed test cases against the application.
4. Recorded actual results and execution statuses.
5. Reviewed test coverage and documented potential defects for verification.
6. Used AI-generated suggestions as a starting point and reviewed test cases for relevance and practical applicability.

## Test Case Documentation

The Excel workbook contains module-wise test cases and execution records, including:

- Test Case ID
- Test Scenario
- Test Case Title
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Priority
- Actual Result
- Execution Status

## Tools and Technologies

## AI-Assisted Testing

AI was used to help generate test scenarios and organize test cases using the CO-STAR prompting method.

The AI-assisted workflow included:

- Generating test ideas for individual application modules.
- Reviewing positive, negative, boundary, and edge-case coverage.
- Structuring test cases in a consistent format.
- Reviewing expected results and identifying possible gaps.

AI-generated test cases were treated as suggestions, not as proof of application behavior. Actual results were determined through manual execution.

## Project Results

Execution results are maintained in the accompanying Excel workbook. Final PASS, FAIL, BLOCKED, and NOT RUN counts should be taken from the completed execution tracker.

Any defect listed in the project should include reproducible steps, expected and actual results, and its current verification status.

- Testing complete e-commerce user workflows.
- Validating input fields and error messages.
- Verifying product details and price calculations.
- Recording execution evidence and defect information.
- Using AI responsibly to support QA test design.
