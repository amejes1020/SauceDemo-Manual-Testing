# AI-Assisted Test Coverage Review

## 1. Objective

To use AI assistance to review the manual test scenarios created for the SauceDemo application and identify potentially missing test conditions.

## 2. AI Tool Used

ChatGPT

## 3. Testing Scope

The review covered the following modules:

- Login
- Products
- Cart
- Checkout
- Menu and Logout

## 4. AI-Assisted Activities

- Review existing test scenarios.
- Identify missing positive test conditions.
- Identify negative and edge cases.
- Suggest boundary conditions.
- Check navigation and end-to-end workflow coverage.

## 5. Human Review

AI suggestions were evaluated against the application functionality. Relevant scenarios were selected and included in the test documentation where appropriate.

## 6. Outcome

AI assistance supported the review of test coverage and helped identify additional scenarios for consideration.

## 7. Key Learning

AI can help testers think beyond basic functional scenarios. However, testers must validate suggestions against actual application behaviour and avoid adding irrelevant or duplicate test cases.
