# AI-Assisted Manual Testing

This folder documents the use of AI tools
to support manual testing activities
for the SauceDemo application.

## AI-assisted activities

- Test scenario generation using CO-STAR prompts
- Test case generation and review
- Identification of missing test scenarios
- Positive, negative and edge-case analysis
- Test coverage review

## Human Review

AI-generated suggestions were reviewed and
validated before being included in the
manual testing documentation.
