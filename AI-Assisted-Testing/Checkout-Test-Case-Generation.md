# AI-Assisted Test Case Generation – Checkout Module

## 1. Objective

To use AI assistance to generate manual test scenarios for the SauceDemo Checkout process.

## 2. AI Tool Used

ChatGPT

## 3. Prompting Technique

CO-STAR framework

## 4. Prompt Objective

Generate 15 practical manual test cases covering:

- Checkout Information
- Checkout Overview
- Order Completion
- Positive scenarios
- Negative scenarios
- Boundary and edge cases
- End-to-end checkout flow

## 5. Human Review

The generated test cases were reviewed for relevance, clarity, expected results and test coverage before being used in the manual testing exercise.

## 6. Execution

The reviewed test cases were executed manually against the SauceDemo application.

## 7. Outcome

The checkout test cases were completed as part of the SauceDemo manual testing portfolio.

## 8. Key Learning

AI can assist with test case design and identifying potential test conditions, while the tester remains responsible for reviewing test cases, validating application behaviour and recording execution results.
